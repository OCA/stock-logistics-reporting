This module adds an optional unit price to the delivery slip report.

The unit price display can be configured per partner through the Render
Unit Price on Delivery Slip setting in the partner's Inventory section.
When enabled, the unit price from the related sales order line is
displayed on the delivery slip. If a picking contains products with
different unit prices, the delivery slip keeps them in separate
aggregated lines. Products with the same unit price can still be
aggregated.

The unit price column is only displayed when the setting is enabled and
at least one delivery line has a unit price from a related sales order
line.

The setting is company-dependent, allowing different configurations for
the same partner across multiple companies.

Usage
=====

To use this module, you need to:

1. Go to **Contacts** and open a partner.
2. In the **Sales & Purchase** tab, locate the **Inventory** section and
   enable **Render Unit Price on Delivery Slip**.
3. Create or open a delivery order for this partner.
4. Print the **Delivery Slip** report.

When enabled, the unit price from the related sales order line is
displayed on the delivery slip. If the picking contains products with
different unit prices, they are displayed as separate aggregated lines.
Products with the s ame unit price can still be aggregated.

The unit price column is only displayed when the setting is enabled and
at least one delivery line has a unit price from a related sales order
line.
