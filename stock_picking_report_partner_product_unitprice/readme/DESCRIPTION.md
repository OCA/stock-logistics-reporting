This module adds an optional unit price to the delivery slip report.

The unit price display can be configured per partner through the Render Unit Price on Delivery Slip
setting in the partner's Inventory section. When enabled, the unit price from the related sales order line
is displayed on the delivery slip. If a picking contains products with different unit prices, the delivery
slip keeps them in separate aggregated lines. Products with the same unit price can still be aggregated.

The unit price column is only displayed when the setting is enabled and at least one delivery line has a
unit price from a related sales order line.

The setting is company-dependent, allowing different configurations for the same partner across multiple companies.
