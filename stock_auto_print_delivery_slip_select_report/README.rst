This module allows to select, for each operation type, which report is
printed when a transfer is validated and the *Delivery Slip* auto print
option is enabled.

By default, Odoo always prints the standard *Delivery Slip* report. With
this module, any report of the *Transfers* model can be used instead
(e.g. a custom ticket format).

Usage
=====

1. Go to *Inventory > Configuration > Operation Types* and open one.
2. In the *Hardware* tab, enable *Delivery Slip* in the *Print on
   Validation* section.
3. Select the report to print in the *Print report* field shown next to
   it.
4. Validate a transfer of this operation type: the selected report is
   printed instead of the standard delivery slip.
