This module adds an instantaneous, location-wise backdated inventory and
valuation report calculated as of any historical cutoff date.

It uses an on-demand pre-aggregated session table (``_auto = False``) to
eliminate database table bloat and support high-performance Pivot, List,
and Graph views.

Usage
=====

To use this report:

1. Go to **Inventory > Reporting > Location Inventory At Date**.
2. Select the **Stock As Of Date** and optional filters (Location,
   Category, Product). Sub-locations and sub-categories are
   automatically included via ``child_of`` resolution.
3. Click **View Inventory** to view pre-aggregated stock quantities and
   valuations.
